在 App 内反馈问题

macOS / Windows 桌面端

装筱窝 → 设置 → 帮助与反馈 → 问题反馈

手机端

装筱窝 → 我的 → 右上角设置图标 → 帮助与反馈 → 问题反馈

问题反馈支持填写文字并附加最多 3 张问题图片。请勿在反馈内容或截图中提交密码、验证码等敏感信息。

联系技术支持

支持邮箱：zxwsupport@yinnkhome.com

为了更快定位问题，建议在邮件中提供：

  • 设备型号和操作系统版本
  • 装筱窝 App 版本号
  • 问题发生的操作步骤和相关截图
  • 错误提示文字（如有）
