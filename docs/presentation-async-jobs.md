# 方案汇报异步生成

项目功能菜单进入方案列表，点击“生成方案汇报”填写设置。提交只创建任务，返回后由服务器生成目录与 PPT，客户端每 4 秒刷新仍在生成的任务。页面离开不影响任务；客户端取消的是轮询，而不是服务器生成。

## 接口

- GET /api/renovation/projects/:id/presentations：最近 100 个任务及结果目录。
- POST 同一路径：settings 与 request_key（一次提交的 UUID）。重复请求返回同一个任务。
- POST /:jobId/retry：仅失败任务重新入队，已保存的资料快照、目录可以复用。
- GET /:jobId/download：已完成任务下载 PPT；始终重新校验项目业主／设计师权限。

任务状态为 queued、running、completed、failed；phase 区分资料读取、目录生成与 PPT 制作。模型或生成错误保存为 failed，列表显示原因。请求中断不会删除数据库任务。

## 存储和部署

任务表 project_presentation_jobs 由后台服务首次启动时通过 CREATE TABLE IF NOT EXISTS 建立，需要数据库建表权限。后台每 3 秒检查队列，每个实例同时处理一项；数据库租约防止多实例和部署预检进程重复执行，20 秒续约，服务中断后 3 分钟租约过期恢复，连续中断超过 3 次转失败。

文件默认存于部署目录旁的 private-presentation-results，例如 /opt/private-presentation-results。可用 PRESENTATION_RESULTS_DIR 指定持久目录；应可写、纳入备份，且不要配置为静态公开目录。多个实例必须共享同一结果目录。目录在部署目录之外，不随后端版本替换；下载接口不返回物理服务器路径。

本机路径仅在用户选择保存位置且下载成功后记入本机 SharedPreferences，按用户、项目与任务隔离。列表显示可选择复制的路径并支持打开文件；移动或删除本地文件后可重新下载。目前本地保存支持既有桌面和移动端文件服务，浏览器端提示使用客户端。

前后端需同步更新以启用列表流程。旧目录／导出接口暂保留兼容旧客户端。后台模型请求保留有限超时作为失败处理，前端不再等待整次生成。真实阿里云调用与生产 MySQL／文件目录权限仍需上线验收，单元测试使用模拟模型和数据库。
