# 产品与材料采集系统 P0 上线阻断修复记录

日期：2026-09-17

范围：只处理首次 No-Go 检查确认的四个 P0，不包含采集并发、依赖升级、迁移 checksum、健康检查、可观测性、优雅停机或 CORS 改造。

## 1. 管理员认证与 Token 失效

- 删除源码中的固定账号密码。
- 管理员用户名、bcrypt 密码哈希、Token 版本和有效期均从环境变量读取。
- 管理员 JWT 增加 `adminUsername` 和 `adminTokenVersion`；校验时必须与当前环境配置完全一致。
- 旧 Token 没有版本字段，因此升级后立即失效。
- 后续需要全量撤销管理员 Token 时，只增加 `ADMIN_TOKEN_VERSION`，不影响普通用户 Token。
- 默认管理员 Token 有效期从 30 天改为 8 小时，可通过 `ADMIN_JWT_EXPIRES_IN` 配置。
- 配置缺失或 JWT 密钥不足 32 字符时，服务拒绝启动。

生产部署前需要由运维离线生成 bcrypt 哈希，并在生产 `.env` 中设置：

```text
ADMIN_USERNAME=<administrator name>
ADMIN_PASSWORD_HASH=<bcrypt hash>
ADMIN_TOKEN_VERSION=1
ADMIN_JWT_EXPIRES_IN=8h
```

## 2. 数据库备份脱离公网目录

- 新备份路径为 `<APP_DIR>.private/db-backups`，与可部署应用目录平级。
- 私有目录权限为 `0700`，备份文件权限为 `0600`。
- 备份文件名包含发布 SHA 和时间戳，便于审计与恢复定位。
- 部署时检查旧版的 `storage/db-backups`；若存在目录，整体移动到私有目录，再继续发布。
- staging 中因保留 `storage/` 而复制出的旧备份会被明确清除，防止重新激活到公网目录。
- CI 增加 `npm run check:public-backups`，只要公开目录中出现数据库备份特征文件就阻止发布。

本次只读检查结果：

- 本地 `server/storage`、`server/uploads`、`server/public` 中未发现数据库备份。
- 公网 `/api/storage/db-backups/` 和 `/api/storage/pre-deploy.sql.gz` 返回 404。
- 公网 `/storage/...` 返回的是与随机不存在路径完全一致的官网 HTML 回退页，不是 SQL/Gzip 文件。
- 未登录生产主机，无法枚举未知文件名；未来部署会在切换前执行主机文件级检查和迁移。

## 3. 无副作用部署烟测

部署烟测显式使用：

```text
APP_RUNTIME_MODE=smoke
```

该模式禁止：

- 启动采集认知恢复、采集任务恢复、AI 恢复和站点规则沙箱恢复；
- 启动演示文稿 Worker；
- 启动公司评分定时器；
- 执行应用启动期自动建表；
- 创建发布上传目录。

烟测仍会建立数据库连接并执行只读的 schema 健康检查，以验证新代码可以在当前迁移结果上启动。

## 4. 可审计发布版本

发布提交只包含后端运行时依赖闭包、采集后台静态资源、数据库迁移、相关测试、测试所需的冻结站点规则样本、部署工作流和本修复记录。运行期素材、临时文件、无关研究输出、其他客户端工程以及无关文档不进入发布提交。

发布前必须满足：

1. `app.js` 的所有本地 `require()` 均能解析到 Git 已跟踪文件；
2. 21 个产品与材料迁移文件全部进入同一提交；
3. `npm ci` 后全量测试通过；
4. 公开目录备份检查通过；
5. `git diff --check` 通过；
6. 记录唯一完整 commit SHA，部署只允许从该 SHA 复现。

## 第二阶段建议（本轮不实施）

### 采集全局并发

建议增加单实例全局任务槽位或数据库租约，先从 1–2 个并发任务开始，并把浏览器渲染单独限流。风险是高并发耗尽 512MB 内存、数据库连接和第三方 AI 额度；多实例部署时仅内存锁无法防止重复执行。

### 生产依赖漏洞

建议分别升级 `sharp`、`mysql2`、Express/`qs` 链路，并针对 `pptxgenjs`/`image-size` 做兼容性验证后决定升级或隔离不可信格式。风险是图片解析拒绝服务、数据库压缩协议资源耗尽以及请求参数解析拒绝服务；直接自动修复可能引入 PPT 生成兼容性回归。

### 迁移 checksum

建议在发现已执行迁移时强制比较数据库 checksum 与当前文件 checksum，不一致立即中止部署；同时禁止修改历史迁移，只能新增迁移。风险是当前静默跳过被修改迁移，导致不同环境同名迁移实际结构不同。

### 生产环境契约

建议增加独立、只读的生产配置预检，覆盖采集 AI、Chromium、OSS、Redis 和字体/二进制路径，并统一 CI、Docker、生产机 Node 版本。风险是健康接口正常但动态网页采集或 AI 分析在首次任务时才失败。
